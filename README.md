# Clip n Ship public website and legal pages

Upload `index.html`, `terms.html`, `privacy.html`, and `logo.png` to the **root of a separate public GitHub repository**. Do not upload the Clip n Ship desktop application's `app/static/index.html` or its source code.

## Required before publishing
- Replace every `[INSERT ...]` and `[VERIFY ...]` placeholder in all three HTML pages.
- Confirm the Terms and Privacy statements accurately reflect the actual product and data handling.
- Use a real public contact email and correct operator identity.
- If using GitHub Pages, enable Settings > Pages > Deploy from branch > main > /(root).
- Check the public site and legal pages in a private browser window.

These documents are starting drafts, not legal advice or a guarantee of TikTok approval.
